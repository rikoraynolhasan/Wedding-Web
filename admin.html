Hubungkan Supabase

Siapkan database bersama agar buku tamu bisa dikelola dari perangkat mana pun.

  1. Jalankan supabase/schema.sql di SQL Editor proyek Supabase.
  2. Isi Project URL dan public anon/publishable key di js/supabase-config.js. Jangan pernah taruh service-role key di website.
  3. Buat akun admin di Supabase Authentication dan matikan pendaftaran akun publik. Daftarkan email admin lewat SQL Editor:
    insert into public.wedding_admins(user_id) select id from auth.users where email = 'EMAIL_ADMIN' on conflict do nothing;
  4. Publikasikan website melalui HTTPS. Kunci public aman digunakan karena aturan database membatasi penghapusan untuk admin.
